## About me

I'm a Full Stack Developer at **Subh Sankalp Pvt Ltd**, Noida. I build and run the company's in-house real estate CRM, which sales and accounts staff use every day across 4 townships: 970+ plots and 2,600+ receipts.

- Merged three separate township CRMs into one multi-project system, and reconciled ₹60+ crore of migrated receipts to the rupee.
- Wrote a one-way sync service so two live legacy portals feed the central CRM.
- Built in-browser OCR (Tesseract.js) that fills Aadhaar/PAN details from a photo, and an Android app from the same React code with Capacitor.
- Run four .NET background workers for token expiry, lead distribution, site-visit status and legacy sync.

B.Tech in Computer Science, VIT Bhopal (2025). Open to Full Stack, .NET and React roles.
